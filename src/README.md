# レトロテトリス - 8bit スタイル

ブラウザで遊べる80年代の8bitゲーム機スタイルのテトリスゲームです。

![Tetris Gameplay](https://github.com/user-attachments/assets/15075679-cd86-4cdf-a10f-ae40d2627703)

## 特徴

- 🎮 **クラシックなテトリス体験** - 7種類のテトロミノピースで遊べます
- 🕹️ **80年代の8bitスタイル** - ドット絵風のピクセルアートとレトロなビジュアル
- 💚 **CRTモニター風のエフェクト** - 緑色のグロー効果で懐かしい雰囲気
- 📊 **スコアシステム** - ライン消去でスコア獲得、レベルアップで難易度上昇
- 👻 **ゴーストピース表示** - 落下予測位置を半透明で表示
- 💾 **ハイスコア保存** - ローカルストレージにハイスコアを保存

## 遊び方

### ゲームの起動

1. `src/index.html` をブラウザで開きます
2. 「START」ボタンをクリックしてゲーム開始

### 操作方法

| キー | 動作 |
|------|------|
| ← → | ピースを左右に移動 |
| ↑ | ピースを回転 |
| ↓ | ピースを高速落下 |
| SPACE | 一時停止/再開 |

### ゲームのルール

1. 上から落ちてくるテトロミノピースを操作して、横一列を揃えます
2. 一列揃えるとその列が消え、スコアを獲得できます
3. 複数列を同時に消すと、より高いスコアを獲得できます
4. 10ライン消すごとにレベルがアップし、落下速度が速くなります
5. ピースが画面上部まで積み上がるとゲームオーバーです

### スコアリング

- 1行消去: 100点 × レベル
- 2行消去: 300点 × レベル
- 3行消去: 500点 × レベル
- 4行消去: 800点 × レベル

## 技術スタック

- **HTML5** - 基本構造とキャンバス要素
- **Tailwind CSS** - スタイリング（CDN経由）
- **JavaScript (ES6)** - ゲームロジック
- **Canvas API** - ゲームグラフィックスの描画
- **LocalStorage API** - ハイスコアの保存

## カスタマイズ

`src/js/script.js` の以下の定数を変更することで、ゲームをカスタマイズできます:

- `COLS`: ゲーム盤の横幅（デフォルト: 10）
- `ROWS`: ゲーム盤の縦幅（デフォルト: 20）
- `BLOCK_SIZE`: ブロックのサイズ（デフォルト: 30px）
- `COLORS`: テトロミノの色設定
